2026-09-07 · Vue 3.4 / uni-app / SCSS。当前交付 H5；微信小程序保留编译与交互降级。后台不在本轮范围，图片生成不接入。

## 方向

成年人备考工具，不是营销落地页。首页先展示今日学习，再提供方法、报告和购买入口。暖白纸面、石墨蓝标题、蓝色主操作；用留白、行距和细线建立层级，取消彩虹配色、装饰光晕、假原价、满页超粗字体。

UI/UX Pro Max 搜索结果：`professional editorial minimal` 命中 Minimalism & Swiss Style，采用其功能性排版与低成本反馈。教育关键词最初命中儿童 Claymorphism，已拒用。Vue 动效检索两次未命中，动效使用 skill 通用规则与现有 uni-app 平台能力，不声称来源于该数据库匹配。

## 交互与动效

- 按压：100ms 透明度反馈，不改变布局尺寸。
- 列表展开 / 内容进入：180–220ms opacity + translateY(6px)，不动画 height，不持久设置 will-change。
- Tab：点击自身不重载；其他 tab 进入时轻微淡入，无模拟整屏侧滑。
- 月报：uni swiper 原生滑动实现，增加上一月 / 下一月按钮和页码，不自动轮播，不拦截纵向滚动、浏览器边缘返回或缩放。
- 学习路线：4 段折叠，标题按钮暴露展开状态，允许全部展开；内容在关闭时移出可访问树。
- 加载 / 错误：独立加载占位、明确重试按钮；不能把旧统计当作加载成功。
- 系统 reduce motion：关闭位移和过渡，内容直接显示最终态。小程序通过 uni.getAppBaseInfo 的 theme 之外不猜测减弱动效；动画默认克制。
- 触觉：H5 不强行调用 navigator.vibrate（iOS 不支持且不应每次点击震动）；小程序仅用户在本机启用 `sxb-haptics` 时，关键确认使用 uni.vibrateShort。
- 不使用 GSAP / WebGL / 粒子 / 无限闪烁 / 滚动劫持。关键路径仅 CSS transform/opacity。
