# 上行宝 Logo 设计提案

本目录是独立设计交付，不影响现有用户端、管理后台和资源上传流程。

打开 `index.html` 即可离线查看三个方向、横排组合、实际小尺寸、黑白版，以及可切换方向的应用示意。每个方案的小尺寸检查下方新增 APP 图标、官网 Logo、海报 Logo 三种应用展示，便于并排比较。`overview.png` 是方便分享的对比总览。

## 品牌依据

依据本项目的实际资料：

- `apps/user/README.md`：uni-app 用户端，目标为 H5 和微信小程序。
- `apps/user/src/pages/index/index.vue`：定位为“全链路备考”，核心文案为“把知识学懂，把每一道题做会”。用户按考试认知、知识理解与刷题、薄弱点强化、背诵冲刺四个阶段复习。
- `apps/user/src/mock/data.ts`：已有考试类别包含社会工作、财会经济、教师资格和医药卫生等。类别是项目示例信息，不作为全部已经上线的承诺。
- `apps/api/src/site-settings.ts`：服务包括知识点、课程、题库和学习计划，不承诺考试通过。
- `apps/admin/src/styles/components.css` 与用户端首页：采用 `#3569E8` 蓝色；管理主样式另有 `#315BD6`，本次提案统一采用前者。

设计判断：面向职业资格备考用户，选择清晰、可靠、稳步掌握的气质。避免少儿化、金融收益暗示和“保过”表达。预览口号“每一步，都向上。”为此次创意提案，并非已确认的品牌口号。

UI/UX 技能初次查询偏向少儿教育的玩具感与 3D 风格，不适合本项目，也与扁平 Logo 要求不符，未采用。复查“Minimalism & Swiss Style”后，采用留白、网格、少色与高对比原则。配色以项目代码为依据。

## 三个方向

### A · 上序（推荐）

从“上”字提取竖干、短横与基座。两处一致的切角暗示前进，基座与竖干之间的留白对应分阶段学习。

优点是中文名称联系直接、节点少、小尺寸识别稳定，也容易延续现有蓝色界面。取舍是气质更理性，图形偏汉字构成。

### B · 行带

以 SXB 首字母 S 为骨架，用一条连续带连接上下两段学习过程。斜向负空间与切角形成更有动感的数字品牌轮廓，没有强行把 X、B 同时塞入图形。

适合数字工具与学习进度相关延展。与中文品牌名的关联较弱，建议早期与文字组合使用。

### C · 知展

两片错位展开的知识页，也可读作舒展的双翼。中央的开放通道强调持续学习，从理解到独立运用。

曲线更温和，适合学习服务的陪伴感。书页、生长的意象更常见，品牌名称专属性不及 A。

## 文件结构

每个方案目录中包含：

| 文件 | 用途 |
| --- | --- |
| `mark.svg` | 品牌蓝图形标，256 × 256 viewBox，背景透明 |
| `mark-black.svg` | 纯黑图形标 |
| `mark-white.svg` | 反白图形标，在浅色软件背景中可能看不清 |
| `lockup.svg` | 蓝色图形与深色中文横排组合 |
| `lockup-black.svg` | 纯黑横排组合 |
| `lockup-white.svg` | 反白横排组合 |
| `mark-1024.png` | 从 SVG 渲染的透明 PNG，1024 × 1024 |
| `app-icon-1024.png` | APP 图标，1024 × 1024，满底品牌蓝、白色 Logo，无透明通道 |
| `app-icon-640.png` | APP 图标，640 × 640，满底品牌蓝、白色 Logo，无透明通道 |
| `app-icon-64.png` | APP 图标，64 × 64，满底品牌蓝、白色 Logo，无透明通道 |
| `app-icon-rounded-{尺寸}.png` | 与页面示意一致的圆角 APP 图标，含 1024、640、64 三种正方形尺寸，圆角外透明 |

所有 SVG 图形均为手工编写的真实路径，无 `<image>`、Base64、外链、脚本或位图描摹。A 为 2 条路径，B 为 1 条路径，C 为 2 条路径。可在 Illustrator、Inkscape 等软件编辑节点及颜色。

横排 SVG 中 `symbol` 与 `wordmark` 分组独立；中文为真正 `<text>`，**未转曲**。字体为本机已有的 **Noto Sans SC Bold / 思源系无衬线中文**，实际字体 family 为 `Noto Sans SC`，weight 为 700，备选 `Microsoft YaHei`。换设备需安装 Noto Sans SC 以保持一致；确认最终方案后可另存转曲版，不能仅靠修改扩展名得到 AI 源文件。

图形画布已包含周围留白。24、48、128 px 对照指整个 SVG 画布尺寸，图形墨迹小于画布尺寸，这是有意保留的安全边距。预览页中的 App 蓝色底块是应用示意，独立 SVG 仍为透明底。

## 预览操作

- “品牌蓝 / 黑白 / 反白”切换三套方案的展示色及实际横排 SVG。
- 每个方案的“应用展示”固定使用品牌蓝：APP 为圆角底图标，官网为导航横排组合，海报为蓝底反白标识与宣传文案。场景示意不随上方的颜色检测切换。
- 在原三种场景下增加名片、一次性水杯、T 恤衫、宣传册、书籍；每种均可下载独立 SVG，位于各方案的 `applications/` 目录。SVG 中物体与 Logo 均为矢量，文字保留可编辑文本。
- “A / B / C”切换网站导航与 App 图标的应用示意。
- 卡片“适用场景与取舍”可展开查看。
- 各卡片直接下载独立图形或横排 SVG；其余变体在对应方案目录中。
- 页面纯 HTML/CSS/JavaScript，无外部依赖和联网请求，可以双击打开。

## 复现

`source/build.py` 用 Python 标准库生成 SVG、元数据与离线页面。

`source/render-app-icons.mjs` 从原始矢量路径独立渲染每个尺寸的 APP 图标，输出直角满底版和圆角展示版，共 18 个 PNG。设置 `SXB_ARTIFACT_NODE_MODULES` 为含 Sharp 的 node_modules 目录后执行。平台上传优先选择满底版，圆角由平台裁切；网页展示可选圆角版。`qa/app-icons-report.json` 记录实际像素尺寸、颜色与透明度检查结果。

`source/mockups.py` 生成五种实物应用场景，每个方案各一套，共 15 个可编辑 SVG。400 × 280 是效果展示画布，非实物尺寸；这些文件用于设计比较，不是可直接下单的印刷生产稿。

## 制作正式物料需要的资料

当前无需补充资料即可查看示意。确定设计后，按实际制作范围提供：

| 物料 | 内容资料 | 生产规格 |
| --- | --- | --- |
| 名片 | 姓名、职务、公司全称、电话、邮箱；可选地址和二维码 | 成品尺寸、单/双面、纸张与工艺 |
| 一次性水杯 | 杯身文案；可选二维码 | 供应商刀模/展开图、容量、材质、可印范围与颜色要求 |
| T 恤衫 | 款式与底色、正背面文案、印花位置 | 实际衣版、印花尺寸、丝印/热转印/刺绣等工艺 |
| 宣传册 | 产品介绍、课程/服务内容、联系方式、图片、二维码 | 尺寸、页数或折法、纸张、出血与折线模板 |
| 书籍 | 书名、副标题、作者/编者、封底文案；正式出版时提供出版社资料与条码 | 开本、页数、纸张、装订方式、供应商确认的书脊宽度与封面模板 |

名片中的姓名/职务/联系方式为占位内容；宣传册与样书标题为本次设计示意。最终稿按供应商要求处理出血、CMYK/专色、字体转曲与图片分辨率。

`source/render.mjs` 使用 Sharp 渲染真实 SVG，输出透明 PNG、24/48/128 px 检查图以及几何检查记录。设置 `SXB_ARTIFACT_NODE_MODULES` 为含 Sharp 的 node_modules 目录后执行。

`source/overview.py` 使用 Pillow 和本机 Noto Sans SC 字体制作总览图。总览图仅用于展示，设计源文件是每个方案的 SVG。

`qa/` 保存几何与页面检查记录，不属于业务应用测试。
