## 资料导入

中级 Excel 已导入 **654 条正式来源草稿**：1 个科目、13 章、42 节、81 个知识点、517 道题。草稿不出现在学生端；其来源不是测试内容。另有 43 行存在题目关联名称冲突等问题，保留在本地 `.local/source-drafts.json` 的问题记录中，未擅自匹配。

原目录部分章缺少节名称，以“目录未分节，待核对”记录。知识点星级没有从频次猜测，保留 `starsPendingReview`；显示用占位值不可直接作为正式星级发布。知识点正文未凭空编写。

初级 PDF 为双栏排版，题文与答案尚未完成可靠配对，**没有作为正式题库自动导入**。不能把中级 Excel 关联到初级 PDF。后续需双栏提取、答案校验和人工审题后导入。

原 DEMO 示例内容已入库并标记测试。测试标识保存在数据和后台中，但前台并非每一处旧示例都带醒目测试前缀，不可直接用于正式对外教学。

## 尚未完成 / 上线阻断项

- 微信登录、真实短信、微信支付 / 回调 / 退款未接入，测试模式不等于真实支付。
- 主观题有存储、导入字段和预留接口；评分标准未确定，接口明确拒绝自动评分，不生成假分数。
- AI 10 项配置入口均有，但并非 10 个学生端工作流全部接通；答疑、错题分析、计划建议等仍需逐项产品联调。没有真实 Key，尚未验证中转商实调和真实计费。
- 课程视频 / 音频、讲义原文件未提供。已有 HTTPS URL 字段，没有完整上传、转码、对象存储、播放鉴权系统。课程精细播放进度与学习时长可信采集仍需完善。
- 月报使用首次访问时生成历史快照，还不是月初定时任务。掌握提升与章节环比目前没有完整历史口径，不能据此对外宣传学习效果；公开分享页 / 分享授权 / 二维码落地页未实现。
- PDF 导入、富文本所见即所得编辑器、导入后台队列 / 压缩包资源隔离尚未完成；大批量资料应先在本地人工审查。
- 后台仅最高管理员可登录操作；编辑、客服、运营角色已保留数据字段，但权限分配 UI 与细粒度策略尚未开放。
- 用户和订单等部分后台列表暂取最近 200 条；大规模分页、筛选、导出待补。当前不适合多实例高并发部署。
- 部分旧 DEMO 展示与调试入口尚存；协议、客服二维码、通知渠道和部分分享 / AI 入口仍是占位。前台失败 / 空数据状态还需全量回归，不能认定全部页面与原 DEMO 像素级一致。
- 未进行正式渗透测试、压力测试、全量无障碍认证；Linux + PostgreSQL 实机部署、恢复演练及微信真机验证尚未完成。

## UI 检查

按 UI/UX Pro Max 要求采用白色工作台、克制蓝色操作强调、少量青绿 / 琥珀 / 紫色语义色，统一 Lucide 图标，6–8px 边角、可见键盘焦点、表单标签、加载及错误反馈。

已运行后台 1440、375、768、932 横屏视口与 200% 页面缩放检查，使用减弱动效模式；截图位于 `.local/qa`。这是实施与浏览器自检，不是第三方设计认证，也不代表全部 WCAG 条目通过。暗色主题不在本次白色后台范围内。

自动化业务回归覆盖会员、试用、订单、答题、邀请、防越权、数据隔离及导入；后台、H5、小程序构建通过。后台 Element Plus 包仍有体积警告，需要上线前进一步按需加载。
