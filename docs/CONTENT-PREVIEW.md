# 节与知识点预览

知识图谱的节、知识点列表提供“预览内容”图标，编辑抽屉提供“保存并预览”。列表预览读取已保存版本；保存并预览先走原有保存校验，成功后打开预览。

后台抽屉嵌入用户端预览页面，支持 375、390、430 三种手机宽度和新窗口打开。正文复用正式知识点详情的 `KnowledgeReading` / `StudyContent`，可以检查正文、图片以及直接关联的精品课或配套课（图文、音视频、讲义）。草稿、停用内容也可预览。第一期不提供扫码入口。

## 授权与范围

- 管理员通过 `POST /api/admin/content-preview/:id` 生成 15 分钟预览授权；只能为节或知识点生成。
- 授权以加密令牌携带，绑定签发管理员会话、根内容和考试。管理员会话过期、退出或禁用后失效。
- 用户端 `/#/pages/content-preview/index?token=…` 独立加载，不初始化学生账号、会员权益、个人学习数据，也不发送学生 Authorization。
- `GET /api/content-preview/:token` 仅返回该内容、同考试直接关联课程及其必要展示字段。资源接口再次核验当前引用与归属，不能通过更换资源 ID 访问其他内容。
- 不生成学习访问、答题、收藏、笔记、订单或权益记录。该令牌不能调用学生接口。预览失败不会清理现有学生会话。
- 链接读取当前已保存内容，不是不可变快照。持有链接者在有效期内可预览授权内容；不要将其作为正式发布链接。到期界面清除内容，后台刷新可重新签发。

## 配置和验证

用户端地址使用后台构建变量 `VITE_USER_ORIGIN`，未设置时使用 API 返回的 `USER_ORIGIN`（本地默认 `http://127.0.0.1:5174`）。部署时应配置实际用户端地址，并允许后台嵌入该页面。预览接口与其他 API 一样由用户端 `/api` 代理访问。

无需数据库迁移，不新建资源或快照。媒体继续通过已登记资源读取，不开放上传目录。

`tests/content-preview.test.ts` 验证授权、草稿、跨考试隔离、资源归属、范围请求、过期和无业务数据写入；`tests/content-preview.browser.mjs` 验证列表入口、保存并预览、课程、宽度切换、遮罩保护与学生会话隔离。浏览器测试使用隔离数据库，不修改本地业务内容。
