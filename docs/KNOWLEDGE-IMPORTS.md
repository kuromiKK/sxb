# 知识结构、题目导入与来源追溯

知识图谱进入考试项目后，在顶部「导出」前点击「导入」。考试固定，模板绑定考试 ID。新增架构默认只填写科目、章、节、知识点名称，可勾选知识点星级、科目短标题、知识点正文，模板按所选字段生成。章、节按同父级下首次出现顺序追加编号。支持末尾空层级，不支持中间缺层或合并单元格。星级为0–5整数（0表示未评级），科目短标题最多12字，正文按纯文字保留换行、不解析 HTML 或嵌入媒体。

「更新已有内容」按当前考试的节点实际 ID 匹配，仅填写节点ID和选中的字段；模板附节点对照表，含层级、名称、父级、当前星级与短标题。未选字段始终保留，空单元格默认保留原值，也可明确选择清空。星级、正文仅适用于知识点，短标题仅适用于科目；跨考试、缺失、已删除 ID、层级不匹配或文件内同节点值冲突逐行报错。更新正文会整体替换已有正文及图文排版，不导入图片或音视频，媒体仍通过注册上传流程编辑。更新模式保留名称、考试、归属、状态、来源字段和测试标记，通过来源历史记录新文件。

预览显示新增、更新、未变化/重复、异常行数和逐字段的旧值、新值。已有记录在确认时重新检查版本，预览后被修改的行失败，需重新校验；没有变化不增加版本号。新增模式仅对新节点写入可选字段，已有节点保持原值，补充旧内容应切换更新模式。同一新增科目在不同路径提供的短标题一致时共享，不一致时报冲突。历史批次及失败文件保留模式、字段和空值规则；原四列模板和既有批次兼容。

实现上 `import_jobs.headers` 的旧数组继续兼容，新结构批次使用配置对象 `{mode, fields, blankBehavior}`；`rows` 保存预览时的节点版本、选中值和文字差异（不是可恢复的媒体快照）。本次没有增加内容所有者或发布媒体资源类型。

导入按上传、校验、确认、处理、结果分步进行。新增内容为草稿，测试标记默认关闭。同父级同层级的规范化名称（全半角、首尾空格、连续空白）一致时复用 ID；跨章节同名保留。测试标记冲突、多条同名旧节点、已删除节点不自动覆盖。每行目录在事务保存点内完成，父级失败不会留下本行半截结构。失败行不影响其他有效行。

后台 `import_jobs` 保存进度，每次推进最多15行，同一批次串行处理；关闭网页或网络中断后从最近批次继续，不重复创建已成功内容。界面显示文件行数、成功、跳过、失败、待处理和去重后的各级新增/复用节点数。失败文件保留原模板格式，仅保留失败行，另附原始行号与失败原因，修正后可重新上传。

按题型导入共用上述向导，保留题型版本、必填项、知识点所属考试及答案校验。题目内容完全重复时跳过，同题干但内容不同提示冲突；不会自动覆盖原题。模板附带本考试的知识点 ID 对照表，知识图谱导出追加科目、章、节、知识点的实际数据库 ID。

所有导入源 XLSX 经 `/api/admin/media/upload` 注册为 `import` 资源，仅管理员可下载。`content_origins` 关联资源 ID、批次、工作表和行号，允许多次导入留下来源历史。资源引用索引包含批次与内容来源，支持跳转，引用期间禁止删除。

上传计算 SHA-256，同内容复用磁盘文件，每次上传仍分配独立资源 ID，保留文件名、上传人、权限归属与时间。同名不同内容不覆盖；清理资源时只有最后一个资源记录删除才移除共享磁盘文件。历史文件可通过 `scripts/backfill-resource-hashes.ts` 补指纹，不修改旧 ID 或内容。

现有标题/名称查询框同时检索唯一 ID。知识图谱、题目、课程、文章、小抄顶部统一提供「批量操作」。默认显示全部正式/测试内容，可按考试、类型、标记、当前状态及标题/ID筛选。知识图谱的考试详情内锁定当前考试。支持操作所选或全部筛选结果（最多10000条），确认前读取实际 ID/版本快照并显示数量，确认后每100条处理一批、显示进度和逐条成功/失败原因。内容字段、关联和测试标记保持不变，记录发生变化或不符合确认时的筛选范围则失败。考试项目不参与批量操作。

批量操作按入口模块限定内容范围，前端筛选和后端查询/执行都检查模块。知识图谱只包含科目、章、节、知识点；题目、课程、文章、小抄入口各自限定所属类型。知识图谱、题目、课程、小抄沿用原列表的「草稿、审核中、已发布、停用」，提供启用、停用、发布、转为草稿、提交审核，不出现上下架选项。文章沿用文章管理的上架/下架操作与状态。筛选、按钮、确认说明和逐条结果使用相应模块的术语。

停用/下架共用现有 offline 存储值并保留先前状态；启用恢复先前状态，无记录则恢复草稿，不自动发布。转草稿清除恢复状态。发布复用内容、资源校验，教学内容的草稿需先批量提交审核；文章沿用可直接上下架的规则。单条失败通过保存点隔离，不回滚其他成功项；相同状态不重复增加版本号。批量操作写入对应中文操作日志。隐藏目录会影响下级可见性，不改写下级状态。
