## 启动与数据

需要 Node.js 24，分别在项目根目录和 `apps/user` 执行 `npm ci`。本机已经安装依赖并配置 `.env`。

项目根目录运行：

```powershell
node scripts/start-local.mjs
```

脚本不会占用 3000，不会停止已占用端口的进程。端口被其他程序占用时，应先核实所属程序；不要直接结束所有 Node 进程。日志位于 `.local/api.out.log`、`.local/api.err.log` 等文件。

本机数据库是 PostgreSQL 内核的 PGlite，持久保存在 `.local/database`，重启不会清空。**同一目录只能由一个 API 进程打开**；API 运行时不要另外执行 `npm run seed`。迁移在启动时执行，示例数据只插入不存在的 ID，不覆盖后台已编辑的内容。

备份需先停止此项目 API，再复制 `.local/database`、`.local/secret.key` 和 `.env` 到受保护的位置。数据库和加密密钥须配套保管。不要将这些文件、证书私钥、真实 AI Key 上传 GitHub。

## 推荐验收顺序

1. 后台登录，查看考试与考期，将需要测试的考试日期修改后保存。
2. 在知识点结构中检查科目、章、节、知识点；课程可关联到节或知识点。
3. 题库管理下载模板，填写题目、答案、知识点 ID；预览校验通过后导入草稿，再编辑发布。
4. 用免费学生登录，选择考试，购买 VIP 或 1 元体验，完成模拟支付；刷新仍保留订单和权益。切换另一考试，权益不共享。
5. 做题、写笔记、收藏、清空错题本，再登录检查保存情况；清空错题本不会删除答题历史。
6. 用 SVIP 测试账号查看已有月份报告和二态学习日历；公开分享网页未开放。
7. AI 配置中心选择功能，配置、启停、测试连接，点击用量查看当天接口、模型、Token 和费用。

AI 真实测试需要填入服务商 Base URL、实际模型 ID、Key，选择真实接口模式并保存。点击测试会明确提示可能产生费用。单价单位为人民币 / 百万 Token，预设值仅供配置参考，应按自己的中转商账单核对；上游不返回用量时费用显示未知，不伪造为零。

构建小程序成功不等于真机验收通过：仍需配置公网 HTTPS API 地址、微信合法域名、AppID，并在开发者工具与真机测试。
