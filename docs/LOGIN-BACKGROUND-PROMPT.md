# 登录页可选背景图提示词

当前版本使用代码绘制棋盘格和底部学习装饰，不依赖背景图片。以下提示词用于后续替换为插画，不是必须素材。

## 可直接复制到作图软件

为中文备考学习平台「上行宝」制作手机登录页的背景插画，竖版 9:19.5，建议 1080×2340。整体为清爽、有活力的品牌蓝色，主色 #3569E8，带很淡的同色棋盘格纹理，不使用红色或橙红色背景。扁平矢量插画质感，圆润几何造型，精炼深海军蓝 #14264F 描边，少量纸张质感，年轻但不幼稚。

画面上方及中间约 80% 保持干净，只有低对比度蓝色棋盘格，用来叠加平台 Logo、手机号输入框、按钮和协议文字，不能放任何人物或复杂图案。所有装饰严格集中在最底部 20%：两本拟人化的学习笔记本，一本淡紫蓝，一本奶油黄，表情简洁友善；右侧一支鼠尾草绿铅笔；少量白色四角星和上升的小几何形状。构图自然错落，两侧可轻微出画，中间留白，传递陪伴学习、持续进步的感觉。平面正视角，轻微倾斜的物件，只有少量柔和阴影。

不要生成任何文字、字母、数字、Logo、水印、二维码、手机外框、输入框或按钮。不要火焰人物，不要复刻其他产品的品牌或吉祥物，不要写实照片、3D 渲染、复杂渐变、强光或密集装饰。

## 接入要求

Logo、表单、按钮、协议文字继续由页面真实渲染，不能烘焙进背景图。新增可配置图片时，通过资源上传登记流程保存，不在业务记录中存 Base64。
