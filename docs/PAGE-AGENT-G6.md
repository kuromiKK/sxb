# Page Agent 与 G6 配置

## 使用入口

系统设置 → 接口配置提供 AI员工、G6 图谱两张配置卡。

AI员工的服务商、API 地址、API Key、模型、定价、超时和模型用量限制统一在“AI配置与数据 → AI员工 → 配置”中管理。系统设置只管理外观、员工名称、页面范围、任务步数、操作确认和工作说明，提供跳转至统一配置页的按钮。

Page Agent 使用官方 `page-agent`、`@page-agent/page-controller` 1.12.4，后台顶部“AI员工”打开中文侧边面板。保存模型连接、启用并选择允许工作的页面后，可以描述任务、查看步骤、补充回答或停止任务。默认逐步确认点击、填写、选择操作；已经完成的操作不会因停止任务而撤销。

所有 AI 功能的接口编辑抽屉都在 API Key 右侧提供“测试并获取模型”。先填写模型 API 根地址（HTTPS，不含 `/chat/completions`）和真实接口必填的 API Key，点击测试，再从下拉列表选择模型并保存。已保存的密钥无需重复输入；更换 API 地址需要重新填写密钥。地址只有域名时按标准兼容接口补全 `/v1`，其他路径保留。本地测试模式无需密钥。

读取列表通过服务器 GET `{baseUrl}/models` 完成，不需要先保存，不发起生成调用，不把草稿密钥写入数据库。服务商需要支持兼容的 `{data:[{id:"model-name"}]}` 格式；未授权、空列表、不支持该接口会显示明确提示，不会使用虚构模型列表。更换地址或密钥会清空列表。保存新的连接或模型时，服务器会核验当前管理员在15分钟内对同一地址及密钥成功读取的模型列表；服务重启后需重新读取。未改动已有连接与模型的外观修改无需重新测试。

列表来自服务商，不保证所有返回模型都支持 Function Calling。选择并保存后，点击 AI员工列表行的“测试连接”进行工具调用测试，会产生少量模型用量。AI员工固定使用真实接口、Chat Completions 协议和支持 Function Calling 的模型；其他 AI 功能保留既有运行模式和协议选择。

密钥沿用服务器加密存储机制；运行时浏览器只向本站已认证的管理接口发送请求，由服务器携带密钥调用模型。浏览器传入的模型名不会覆盖后台设置。公网 HTTPS 上游检查复用已有 AI 服务；不支持内网或 HTTP 模型地址。页面文字将提供给所配置的模型理解任务，请按业务需要选择开放页面。

若系统把模型域名全部解析到代理 Fake-IP 网段 `198.18.0.0/15`，服务器会通过系统配置的 DNS 服务器再次查询真实 IPv4 地址。仅在全部结果均为合法公网地址时继续请求，并固定经过校验的地址、保留 HTTPS 证书校验。IP 字面量、其他内网地址、混合地址不会触发此回退；回退失败仍拒绝连接。若仍提示“API 域名解析到了内网或保留地址”，请求尚未发出，不能据此判断密钥错误，可在代理中配置真实 DNS。不要把保留地址加入允许列表或关闭地址校验。

AI员工面板将平台错误转换成 Page Agent 可识别的错误格式，显示具体中文原因。本站接口 404 与模型服务接口/模型 404 分别提示；模型失败原因也写入用量记录，不记录密钥或原始上游错误正文。

员工名称、工作说明、允许页面、每任务步数、单次超时、每管理员每日模型调用次数均可配置。每日限额按北京时间统计，测试及失败模型请求也计入；一个任务可能有多次模型请求。操作沿用当前管理员身份及现有接口权限。执行过程不会开放 JavaScript 执行工具，也不修改服务器代码；关闭网页后不继续后台运行。

外观配置支持跟随系统、浅色、深色，以及主色、浅色面板背景、深色面板背景。跟随系统监听设备配色偏好；预览和实际面板共用配色逻辑，文字和按钮文字自动适配背景。右侧预览无需密钥、不调用模型，保存后应用于真实面板。旧配置自动使用默认外观，无需重新填写模型密钥。当前入口仍位于顶部。

配置变更、模型请求结果及任务摘要记录到操作日志。日志不保存 API Key、完整模型请求或原始响应。Page Agent 主要依据当前页面内容执行任务，本次没有另行接入知识库检索。

迁移后的 AI员工模型调用也写入统一的 `ai_calls`，可通过 AI配置与数据中的“用量”查看；只保存用量与结果状态，不保存页面正文。旧操作日志继续保留，不凭空补算历史费用。迁移时没有价格依据，默认零价格对应的 AI员工调用费用标记为未知，填写计价后按返回的 Token 数估算。

## G6 外观

G6 是本地前端图谱库，不需要外部 API Key。颜色与样式保存在服务器，应用于知识图谱的关系图谱、思维导图。

- 三套预设；考试、科目、章、节、知识点、课程六种节点颜色。
- 渐变、柔和、描边节点样式；圆角、字号、阴影。
- 关系图与思维导图各自的连线类型，以及线宽、虚线。
- 画布背景、网格、高度和动画；尊重系统减少动画设置。

编辑时右侧使用真实 G6 图谱预览。预览区固定高度便于编辑，实际页面采用保存的画布高度。“恢复默认”先修改表单，保存后才应用。

## 存储及验证

外观与操作配置保存在 `integration_settings`，AI员工服务配置统一保存在 `ai_features` 的 `page-agent` 记录。启动时事务迁移原模型地址、模型、加密密钥、超时与每日限额，随后清除旧位置的服务字段和密钥副本。重复启动不覆盖已经迁移的服务配置；版本校验防止覆盖他人更新。启用 AI员工时需要同时开启员工和对应的模型服务。

验证命令：

```sh
npm run check
node --experimental-strip-types --test tests/workspace-tools.test.ts tests/integration-connection.test.ts
node --experimental-strip-types tests/workspace-tools.browser.mjs
npm run build:admin
```

浏览器回归使用隔离数据库、真实 Page Agent 执行循环及模拟模型响应，验证配置持久化、实际 G6 样式、表单操作确认、抽屉旁输入、停止和页面限制。没有使用生产密钥，也不代表已验证某个真实模型账号；请保存自己的模型配置后执行连接测试。
