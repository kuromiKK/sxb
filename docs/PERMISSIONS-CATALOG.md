# 全站权限清单与后台配置要求

更新日期：2026-09-08。

本轮实施进度见 [考前小抄与知识点课程开发记录](STUDY-CONTENT-DELIVERY.md)。现已新增按考试配置现有免费版/VIP/SVIP权限的后台与接口，但本清单中尚未落地的独立权限项仍为规划项，不能据此认定已全部实现。

## 状态与用途

用户明确要求：项目中提到的所有权限必须单独记录，后续在后台管理不同会员及其功能权限。

本清单核对了现有会员计算、API 校验、前端入口及产品对话，是包括未来需求的权限基线。当前已实现现有免费/VIP/SVIP的按考试权限配置；本文标识尚未全部注册到代码或数据库。新增功能必须更新本清单；不得以会员展示名或前端按钮隐藏替代服务端鉴权。

标注含义：

- **已确认**：用户已明确的规则；与旧代码冲突时，后续按新规则实现。
- **现有实现**：代码目前的行为，不代表用户已经确认其为最终规则。
- **待确认**：不得擅自决定会员门槛、次数或收费规则。

## 会员、期限和权益来源

| 规则 | 已知要求或现状 |
| --- | --- |
| 考试范围 | 用户明确：每个考试独立购买和获得权益；账号手机号相同不意味着跨考试通用 |
| 当前年度 | 同一考试所有人共用当前考试日期，自动进入已配置的下一年度，不让用户各自选择购买不同年度 |
| 默认产品 | 当前免费版、VIP 599 元、SVIP 799 元；新后台需支持配置会员权限组合，不能只改展示名称 |
| 正式权益到期 | 已确认：VIP 到考试结束变免费；SVIP 到期变为该考试 VIP，并按下一阶段期限处理 |
| 一元体验 | 已确认：VIP 24 小时；现有实现每用户每考试使用一次，不可当作正式 VIP 补差价升级 |
| 推荐码体验 | 已确认：可附带 VIP/SVIP 1—72 小时，也可不附体验；可兑换有效期与激活后时长分别记录 |
| 推荐码与已有会员合并 | 待确认：体验到期恢复、多个权益来源冲突、考试日期与体验时长冲突 |
| 人工权益 | 已实现：管理员按用户、考试设置免费/VIP/SVIP或恢复订单权益，有原因、操作人、前后值与版本记录 |
| 人工覆盖优先级 | 现有实现：有效人工覆盖优先于订单；自定义方案和推荐码加入后需明确完整合并规则 |
| 升级 | 已确认：正式 VIP 升 SVIP 默认 200 元；客服可手动调整并留记录，不能低于 100 元 |
| AI 功能启用 | 现有后台每个 AI 功能独立配置/启停、测试、调用记录、token 和费用；会员权限不等于服务已开启 |
| AI 用量 | 现有 AI 配置有额度约束；未来各方案的次数、重置周期、费用规则须单列，不只记录开关 |

会员方案配置必须区分：功能开关、额度、有效期限、考试归属、来源。尚未明确的自定义会员价格、到期降级映射、继承关系和旧订单迁移规则，不自行推定。

## 可配置权限的开发方向

用户已要求后台能够配置不同会员的功能权限。下列为整体方向；权限目录、现有三级考试权限绑定、统一计算及变更审计已实施，其余仍待对应产品需求：

1. 建立权限目录：标识、中文名称、所属模块、动作、作用范围、开关或额度类型、默认规则、确认状态。
2. 建立会员方案与权限组合：按考试配置免费/VIP/SVIP及未来方案。系统凭权限标识判定功能，不凭显示名称判断。
3. 建立用户权益来源和期限：购买、人工开通、体验分别记录；来源冲突和到期计算统一处理。
4. 服务端统一计算有效权限，前端用同一结果展示入口、会员提示和额度；播放、下载、生成等接口仍独立校验。
5. 资源自身的发布状态、开放时间与用户数据归属继续有效，勾选会员权限不绕过这些条件。
6. 后台变更保留版本、操作人、时间、原因及修改前后值。更改是否立即影响存量会员需提前定义，避免配置修改意外改变已售权益。
7. 后台提供“选择考试和会员方案查看权益”的预览及测试依据；是否支持直接模拟用户另行确定，不能用前端调试状态代替真实鉴权。

## 现有代码差异与迁移检查

- `apps/api/src/permission-policy.ts` 注册17项权限，`membership.ts` 合并默认值与考试配置；基础学习项固定开放，其余已注册项可在后台组合。配置立即影响对应考试存量会员的后续请求，并保留版本、原因和审计记录。
- 当前旧标识映射：`reports.read` → `reports`，`ai.knowledge.ask` → `aiChat`，`ai.review.generate` → `aiReview`，AI 错题/报告/计划分别为 `ai.wrong` / `ai.report` / `ai.plan`。节级四项仍合并为 `courses`；客观题、目录、笔记、计划对应固定项 `questions` / `knowledge` / `notes` / `plan`。未来登记项不自动视为已落地开关。
- 课程详情接口目前整篇按课程会员门槛限制，不能直接用于实现“知识点图文免费、媒体付费”。
- 新 AI 老师要求 SVIP，但旧知识点 AI chat 接口允许 VIP；必须单独映射或明确迁移，不无意改变任一功能规则。
- 新 AI 复习资料门槛未定，旧接口为 SVIP；文案和开发需保留这种区别。
- 现有 AI 复习资料历史查询仅按本人限制；未来读取、生成、导出、过期后的查看应分别确认。
- 小抄日常复习提醒遵循学习计划设置；本轮已增加独立的一次性开放通知，不受休息日和复习提醒开关影响。
- 前端仍存在旧基础版/专业版/旗舰版调试名称以及固定权益文案；将来必须与真实方案一致，调试状态不能授予服务端权限。
- 个人“我的权益”已由服务端有效权限名称驱动；首页营销版本卡仍有既有静态文案，尚不属于完整自定义会员产品系统。
- 本轮不迁移已售订单或覆盖个人会员等级，只增加权限策略及内容资源数据库结构；变更权限配置会影响其功能可用性。

## 每个模块的验收要求

- 免费、VIP、SVIP及体验态分别验证；切换考试不继承别的考试权限。
- 未登录、未开放、已过期、禁用、无文件、额度耗尽分别有明确行为。
- 前端提示、后端接口、直接媒体/附件访问和导出结果一致。
- 不能通过改前端缓存、会员名称、请求里的考试/用户/资源 ID 绕过限制。
- 后续每次新增、调整或废弃权限，同步更新本清单、默认会员映射、接口校验和相关测试。
