# 可配置题型

题型跨考试复用，题目仍属于一个考试，可关联该考试下多个知识点。

## 操作入口

- 后台「教学内容 → 题型管理」：四种预置题型，支持新建、复制、编辑、启停。
- 结构设计：公共材料、共用选项、单选、多选、判断、主观作答、小题组。点击添加，选择小题组后添加组内组件，上下箭头调整顺序；属性区设置录入必填、学生必答、默认内容、选项上下限、选项来源及分值。
- 考试评分配置：未单独配置的考试继承组件默认规则；支持多选全对得分、漏选按正确选项给分（错选零分，总分封顶）。
- 录入与答题预览：临时样例不创建题目；先在录入预览填写内容，再在手机外观的答题预览操作。
- 题目管理：新增与编辑读取所选题型版本；固定保留考试、知识点、A–E等级、发布状态等基础字段。
- 题目管理中的导入与导出：先选考试及题型。导出可选历史版本；按版本分别导出以避免不同结构混列。

## 数据与兼容

Migration 13 新增 `question_types`、`question_type_versions`、`question_submissions`。不重写已有题目，不改变题目ID、知识点关联、等级或已有答案。

题目 payload 使用 `type: configured`、`templateId`、`templateVersion`、`definition`（录入时应用考试规则后的服务端快照）和 `values`。客户端提交的 definition 不被信任，服务端按保存版本生成，编辑原题保留快照。旧版 single/multiple/subjective 数据继续兼容，使用新录题编辑器保存时转换。旧主观题已有满分会被保留。

每次保存题型新增不可变版本，编辑旧题不会强制升级。停用题型禁止新增引用，已引用题目仍可编辑与作答。导入预览及提交均校验题型启用状态、当前版本及同考试知识点关联。

公共目录按字段白名单输出作答内容，不输出答案、解析、参考答案和评分要点；提交后才返回相应反馈。配置题型通过 `/answers/configured` 作答，支持幂等重试。纯客观题同步现有 answers 和学习统计；含主观作答的组合题保存在 question_submissions，不按客观对错写入答案统计，可在章节与知识点练习中作答。

## 主观题：AI 判分与自评

主观作答组件的 `aiGrading` 开关默认关闭。关闭时提交后展示参考答案及评分要点，学生可保存0到满分、最多两位小数的自评分，结果明确标记「自评分」「参考总分（含自评）」，不计入客观正确率。未填写自评分时保持 NULL，不默认为0。

开启 AI 后，后台保存及 Excel 导入均要求参考答案、评分要点和满分。使用「系统管理 → AI 配置与数据 → 主观题判分」中配置的真实接口、模型、提示词、超时及限额。配置面板提供推荐提示词按钮；原有自定义提示词不被覆盖。服务端补充固定输出格式与评分边界要求，学生作答和材料作为数据传递，AI 回复需包含每个小题的分数及点评；缺题、重复、越界、格式无效均视为失败，不能生成分数。mock 适配器不会产生有效评分。

Migration 14 为作答增加题目快照、判分尝试次数及处理时间。先事务保存作答，再执行 AI 调用，不持有长数据库事务。失败可通过 `/answers/submissions/:id/retry` 显式重试，同一提交的网络重试不会重复发起调用；并发判分采用数据库租约，同一作答最多10次尝试。AI 耗时和费用沿用 ai_calls 日志。主观结果按字段区分 AI、自评；全部字段完成后才汇总分数，部分失败不算0分。

`/answers/submissions/:id/self-score` 仅允许本人修改自评字段；`GET /answers/configured/:questionId` 恢复本人最新已提交作答及其原版本。历史题型和题目不会强制升级，题目编辑器提供「更新至最新版本」按钮，确认后保留标识相同的组件内容。Migration 14 之前的作答不推断评分快照，可重新作答使用新流程。

## Excel

使用现有 ExcelJS 输出原生 xlsx，每行是一道完整题。参照提供的历年真题表，选择题的选项 A、B、C…各占一列，生成到组件配置的选项上限，前 N 列按下限标为必填。选填选项必须连续填写，不能跳空。共用选项也使用独立列；引用它的小题不重复生成选项。判断题无选项列，答案填写「正确／错误」，附 Excel 下拉校验；主观题包含参考答案、评分要点，AI 开启时标记必填。

固定列包含题目ID、标题、知识点ID、等级、年份、真题标记和题型。标题留空时取首个作答组件题干；知识点ID必填，多项逗号分隔，同一题不能跨考试。原表题库ID不使用；原表题目难度不擅自映射到 A～E 等级。题型留空沿用当前选择，填写时必须匹配，混合题型分开使用各自模板。真题标记支持是/否或1/2。隐藏版本表同时保存模板格式，兼容旧版单列选项模板，新下载统一使用独立选项列。

导入最多2000道题、8MB，预览全部通过后事务提交为草稿，不覆盖已有ID。字段、必填约束、选项数量及答案范围在预览和提交时由服务端题型定义校验。

## 题目列表

列表使用公共筛选样式，按标题、题型、知识点、状态在服务端筛选并分页，初始全部。知识点筛选匹配全部关联关系，包括非主知识点。列表只显示标题、知识点、题型、状态、更新时间、操作。标题单行最多50字并省略，知识点显示首个名称及数量，点击展开完整名称与目录路径。操作为编辑、红色停用／绿色启用图标。启用恢复停用前的草稿、审核或发布状态，未知旧状态恢复草稿，不绕过发布流程；版本冲突禁止覆盖。

## 验证

- `npm test`：原有回归及新增题型集成测试，隔离数据库。
- `node --experimental-strip-types tests/question-types.browser.mjs`：隔离数据库驱动真实后台和 H5 页面，验证模板保存、规则、预览、录题、导出、移动端提交及响应式布局；截图位于 `.local/qa/question-types/`。
- `npm run check` / `npm run build:admin`。
- 在 `apps/user` 下运行 `npm run type-check` / `npm run build:h5`。

本地数据库迁移前停止 API 并备份 `.local/database`；可运行 `scripts/migrate-question-types.ts` 检查原有题目、结构、用户、订单、答案校验和保持不变。API 启动也会幂等执行迁移。
