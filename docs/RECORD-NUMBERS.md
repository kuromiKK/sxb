# 入库序号与知识图谱列表

数据库版本 11 使用 `record_numbers(table_name, record_id, entry_no)` 保存每张实体表独立的入库序号。原主键、外键、前端 URL、内容接口、题目导入关联字段不变。后台通过 `/api/admin/record-identifier/:id` 获取展示和复制值 `原ID-入库序号`；同名 ID 可指定 `table` 消除歧义。

历史记录按 `created_at,id` 补编号；没有创建时间的表按 ID 稳定排序。无法恢复已经删除记录的历史顺序。新记录由数据库触发器和各表独立 sequence 分配，不以当前记录数计算。删除保留编号登记，不复用旧号；失败事务可能造成正常跳号。相同 ID 的更新或重新导入保留原编号。只有具备独立 `id` 的实体表编号；复合关联表、会话令牌表以及兼容视图不单独重复编号。`content_identity` 的编号由实际所属实体表提供。未来新增实体表需在其迁移中建立同样的序号和触发器。

科目、章、节排序路径是当前兄弟节点按排序字段排列后的序号（如 `1-3-9`），与入库序号无关。筛选与分页不重新计算路径。知识点题数来自题目关联表，课程是否来自实际关联课程，包含草稿和停用内容，表示是否已配套。

知识图谱停用节点后隐藏前端对应目录及后代，但不删除子记录。启用恢复停用前的草稿/审核中/已发布状态；旧的已下架记录没有前态时恢复草稿，仍需审核发布。启停带版本检查并写入操作日志。

本地迁移前备份：`.local/backups/record-numbers-v11/database`。迁移校验保留 1397 条内容以及考试、用户、订单、答题、学习记录和媒体数据的原始值。
