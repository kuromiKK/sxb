# 系统设置与前端搜索

系统管理 → 系统设置按基本设置、接口配置、AI员工、搜索设置、协议管理、客服设置、关于平台排序。表单使用现有公共组件，配置先保存草稿，预览后发布；前端只读取已发布配置。

接口配置与 AI 员工目前仅显示等待开发，不提供保存、发布或接入开关。接口预留短信（阿里云）、微信登录（网页与小程序）、微信支付、验证码；后续在方案确定后逐一接入。现有“AI配置与数据”继续独立管理。首页配置、薄弱项规则与掌握程度本次不调整。

## 配置与资源

- 基本设置：平台名称、Logo、浏览器图标、前端域名。域名继续同步推荐码所使用的 `system_settings.site_domain`。
- 客服设置：名称、二维码、联系方式、服务时间、说明。「我的」与订单的客服入口共用组件，不再显示模拟二维码。
- 关于平台：介绍图文、运营主体、版权、备案信息。
- 搜索设置：开关、提示语、开放的三种内容类型；没有热门词配置。
- Logo、浏览器图标、二维码及正文插图使用登记上传接口。草稿、已发布配置、协议历史版本均进入资源引用索引，使用中的文件不可清理；资源引用可定位到系统设置对应选项卡。

## 协议版本与登录

用户服务协议、隐私政策独立编号为 V1、V2……。编辑或保存草稿不产生发布版本；发布时保存不可变版本、发布人和时间，内容未改变时不允许重复发布。后台展示当前版本，历史版本可以阅读或载入草稿，再次发布会生成新版本，不覆盖历史。

迁移保留原前端的两篇文字为 V1，不代替运营方编写正式协议。用户端协议页展示版本和更新时间。

1. 用户提交短信验证码，服务端核验账号是否已接受两份当前协议。
2. 未确认时返回 5 分钟有效、一次性的登录确认凭据，不签发登录会话，也不提前创建新账号。
3. 前端弹窗展示两份协议的版本和全文，复选框默认为未勾选。点击“暂不同意”不会完成登录。
4. 勾选后提交准确的版本号；服务端再次检查当前版本。确认期间协议再次发布，返回冲突并要求重新阅读、勾选。
5. 成功后记录账号、协议种类、版本和确认时间，再完成登录。新设备按同一账号查询确认记录；已确认当前版本的账号下次登录不重复弹窗。

协议更新在下一次登录时检查，不主动终止已经有效的会话。管理员登录与内容预览不走学生协议确认流程。

## 搜索

`GET /api/search?examId=…&q=…&type=…&page=…` 检索当前启用考试的已发布知识点、直接属于节的精品课，以及适用该考试或全站的常见问题。停用或删除的父目录下内容不进入结果。配套课、题目、其他考试的内容不参与检索。

标题完全匹配优先，其次标题包含关键词，再其次正文或简介包含关键词。每页 20 条。返回标题、类型和所属路径，不返回受限正文、答案、课程媒体地址；进入正式详情仍执行原有权益校验。常见问题结果定位并展开对应文章。

搜索历史只保存在本机，按考试分开，最多 10 条，可清空；没有搜索行为埋点和热门词统计。

## 数据与验证
