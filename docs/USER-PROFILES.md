# 用户档案

入口：用户与权益 → 用户管理 → 点击姓名或查看图标。列表与筛选沿用公共组件，档案以大抽屉展示，点击遮罩不关闭。

## 数据范围

- 仅展示学员账号，不包含后台管理员。列表按姓名或手机号查询，详情始终使用用户唯一 ID。
- 档案必须选择具体考试，无“全部考试”混合统计。优先选择有记录的考试，也可查看暂无记录或已停用的考试。
- 所有学习、答题、错题本、收藏、笔记、章节掌握、订单、权益履约均由服务端按用户 ID 和考试 ID 双重限制；详情同样校验。查询参数不能扩大范围。
- 账号资料、个人推荐人、账号管理记录属于账号级数据。体验资格遵循账号终身规则，不因切换考试重置；购买和授予明细仍按考试隔离。
- 考试切换会清空旧列表、筛选、分页和详情，并忽略过期响应。

## 页面内容与统计口径

- 用户概览：有内容访问或答题提交的自然日（北京时间）、内容访问次数、有效答题提交、错题本、收藏、笔记，当前考试权益和购买金额。累计支付包含已退款金额，并单列已确认退款金额。
- 学习数据：复用学习数据模块的答题记录、错题本、收藏、笔记详情；学习记录显示访问时间及最近上报位置，不推算观看时长或完成率。
- 章节掌握：按科目、章、节展示题目覆盖率及最近客观判分正确率。分母只含当前可学目录下的已发布题目；多知识点关联的同一道题在父层级去重。自评分不计客观正确率，无判分显示暂无客观判分，不生成主观的掌握等级。
- 错题本遵循显式移出规则，答对不会自动移出。
- 购买记录：后台商品名称、状态、实付金额、时间及订单快照详情；用户档案只读，订单管理仍负责订单操作。
- 权益履约：当前生效权益、人工设置、订单授予及最近 100 条订单/权益变更。授予区分待生效、有效、到期、撤销，体验截止时间与实际权益计算一致。已删除测试订单的撤销记录可追溯。
- 推荐关系：账号推荐人、当前考试使用的运营推荐码及在当前考试有记录的被推荐用户。旧数据没有推荐绑定时间，显示“未记录”，不以注册时间代替。
- 学习计划：仅预留“等待开发”，不新增计算或采集。
- 账号管理记录：分页显示账号相关管理操作；考试权益调整放在对应考试的权益履约中。

## 接口与验证

`/api/admin/user-profiles/:userId/exams/:examId/` 下提供 overview、visits、collections、mastery、orders、fulfillment、relations。学习计划未来可在此作用域扩展。账号资料和 account-logs 位于用户作用域。

无需新增数据库表或迁移。使用既有轻量记录，分页获取明细。接口测试与浏览器测试使用独立临时数据库，覆盖同名用户、多考试隔离、越权详情、去重、错题保留、体验到期、快速切换及窄屏布局。
