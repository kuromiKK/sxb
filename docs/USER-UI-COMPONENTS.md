# 学生端公共组件

第一批从知识目录落地，位于 `apps/user/src/components/ui/`，兼容 uni-app H5 和微信小程序构建。新页面优先复用；现有页面按后续改版逐步迁入，不同时重写全站。

## 视觉约定

`apps/user/src/styles/system.scss` 统一颜色、文字和动效变量。沿用品牌蓝 `--sxb-blue`，白底、浅灰分组、深色正文；不靠大面积渐变区分层级。信息文字不小于 12px，正文推荐 15–16px。小尺寸外观仍保留至少 44px 点击高度。尊重系统减少动态效果设置。

## ScrollTabs 横滑导航

参数：`items: {id,label,caption?}[]`、`modelValue`、`label`（无障碍名称）；`variant` 为 `underline`（默认科目导航）或 `compact`（小型章按钮）。通过 `update:modelValue` 切换。`itemClass` 可供业务定位。

可见项点击不移动导航；被遮住的项仅补足可见区域，不把选中项强行放在开头。支持手机原生触摸横滑、H5 鼠标按住拖动和滚轮、方向键/Home/End、选中指示条过渡。拖动超过阈值后抑制本次点击，防止误选；滚轮到达边界后继续交给页面纵向滚动。桌面监听仅在 H5 注册，组件卸载时清理，不接管手机触摸滚动。避免使用 `scroll-into-view` 替代此行为。

## SlidePanel 内容切换

传入 `panelKey` 和 `direction: next | previous`，在内容改变时执行 240ms 的方向滑入；不循环自动播放。支持 `next`、`previous` 事件处理明确的水平滑动，不拦截纵向滚动。业务负责边界和选中状态，组件不请求接口、不持久化数据。

## 其他已复用组件

精讲课详情复用 `CircleAction`、`ActionButton`、`ReadingSheet`、`ReadingExcerpt`、`StudyContent` 和 `ReadingAudio`。视频直接展示 16:9 播放器；音频独立展示播放、暂停和进度；图文展示后台正文。讲义仅在接口返回下载路径时出现，笔记在底部弹层编辑。关联知识点、课程目录默认仅显示入口和数量，点击后在底部弹层查看，与题目详情保持一致。课程目录按当前科目排序，不混入知识点配套课；配套课入口则限定当前知识点。切换课程不自动标记完成。

`ReadingAudio` 可选 `label`（默认“配套音频”）和 `initialPosition`（秒）；媒体时长就绪后恢复一次有效播放位置，默认不自动播放。除原有 `progress`、`pause`、`error` 外提供 `ended` 事件，由页面决定是否记录学完。精讲课详情离开时卸载播放器并提交进度，音频实例销毁后不会继续播放。

精讲课详情采用内容优先的播放器布局：标题下集中展示时长、学习状态与讲义入口，取消独立进度卡片和装饰性口号；“标记学完”作为正文标题旁的次要操作。正文下用浅蓝、浅绿两个紧凑入口打开资源弹层。图文顶部使用本地字母纹理 SVG，视频不叠加无关装饰。参考 [Dribbble Course player](https://dribbble.com/search/course-player) 的内容分层，沿用本站蓝色体系；UI/UX Pro Max 用于检查信息层级、44px 触控区域、键盘交互和减弱动效。

`ReadingAudio` 的 `presentation="course"` 用于课程顶部：通过 `poster` 显示实际课程封面，无封面或加载失败时显示 CSS 唱片，播放时缓慢转动，暂停和减弱动效模式下静止。课程标题由页面统一显示，播放器内不重复；其他使用方默认外观保持不变。

刷题目录沿用知识图谱的蓝绿顶部、圆角白色内容区、`ScrollTabs` 和 `SlidePanel`，今日计划与 SVG 工具入口紧凑展示。每章直接开始／继续练习，节目录默认收起且不展示节掌握程度。题数复用 `chapterPracticeQueues`，按当前可练习题 ID 去重，包含配置题型中的主观题；科目和章掌握程度只统计可自动判分题的最近正确数／总数。

`readChapterRound` 与 `chapterSessionKey` 供刷题目录和作答页共同使用，按用户、考试、章读取当前轮次，同时兼容旧节练习记录。草稿、历史回看不计入本轮已答，待评分的已提交题计入已答；重练须确认，并保留历史服务端记录与笔记草稿。目录按用户和考试记住科目、展开范围和滚动位置，返回时恢复；个人记录同步失败时展示重试，不显示缓存的掌握百分比。

`CourseCover.vue` 统一精讲课网格与继续学习条的封面。网格使用 16:9，`compact` 为 46px 方形缩略图；接收 `CourseLesson`，优先使用注册资源的 `coverUrl`，空封面或加载失败使用视频、音频、图文三套 SVG 底图。类型与时长以文字显示，图文不显示虚构时长。

精讲课页采用两列网格，复用 ScrollTabs 和 SlidePanel；记住各考试的科目、章节选择。继续学习读取登录用户当前考试的最近课程访问，没有记录时不展示，悬浮在 AppTabBar 上方并预留滚动空间。它是课程入口，不自动播放媒体。

`AppTabBar.vue` 负责全站五项底部导航、图标与选中态。后续优先提取列表行、空状态、表单输入和弹层；存在至少两个实际场景时再统一接口，避免创建没有使用场景的组件。

## 统一确认与提示弹窗

`styles/dialogs.scss` 统一学生端网页的 `uni.showModal` 外观：24px 大圆角白色卡片、最大宽度 340px、内容四周留白，底部按钮独立排列、间隔 12px、至少 46px 点击高度。取消为浅灰底，确认为品牌蓝，保留原来的确认、取消、单按钮提示与回调流程。长内容在正文区滚动，按钮始终留在卡片内。

自定义居中弹窗（客服、推荐码、协议、验证码、删除确认、权益提示、订单等）通过 `sxb-dialog`、`sxb-dialog-actions`、`sxb-dialog-action` 复用圆角、内边距与操作尺寸；验证码保留原本内容宽度，业务主题色保留。新弹窗应使用这套公共样式，避免恢复贴边分割式按钮。阅读底部面板和奖牌完成页继续使用各自的公共组件。

H5 原生弹窗的覆盖仅在 H5 编译；微信小程序的系统 `uni.showModal` 仍由微信控制样式，自定义弹窗共享上述规则。`tests/dialogs.browser.mjs` 验证共用样式、单按钮、确认/取消回调、长文案、小屏/横屏和系统深色偏好；章节回归验证“重练本章”叠加弹窗与取消后保留作答。

## CircleAction 圆形操作按钮

顶部返回统一使用 `CircleAction`，以知识点详情页为样式标准：透明底、22px 返回箭头、19px 爱心收藏，均保留 44px 点击区域；浅底用默认 `tone="ink"`，深色或图片背景用 `tone="light"`。收藏选中改为实心爱心和金色，并提供 `aria-pressed` 状态。知识点详情、刷题、课程及其他页面共用组件，保留各页面原来的返回函数，不改变路由语义。分享暂以禁用图标展示，不能触发伪分享成功。

## 知识点阅读与多媒体

知识点详情参照用户提供的课程详情图：音视频铺满顶部内容宽度，返回/收藏/分享位于媒体顶部渐变遮罩上，随媒体滚动，不另占导航条。无媒体时保留普通顶部导航，不留播放器空位。标题前一行左侧显示科目与章节，右侧有讲义时显示浅蓝色胶囊下载按钮；单份直接下载，多份在 `ReadingSheet` 选择，保留权限与验证码校验。课程中的重复下载按钮隐藏。

下方依次为完整标题、星级/课程类型/题数、正文。知识点页向 `ReadingExcerpt` 传入 `availableHeight`：用实际可用视口高度减去页眉、媒体、底部菜单（含安全区）和正文后的学习入口等区域，再由组件预留展开按钮高度。长正文默认填满剩余区域并渐变收起，使学习入口与底部菜单完整落在第一屏；短正文完整显示，不人为拉伸。展开后自然滚动，再收起恢复一屏布局。H5 监听布局和可视视口变化，小程序通过页面尺寸及内容加载回调重新测量；相对页面坐标避免滚动改变折叠高度。极矮窗口中固定区域本身超过屏高时保留滚动，不遮挡操作或缩小文字。课程权限提示不折叠。精品课和练习沿用原有轻量入口，不增加选项卡。底部目录和笔记使用包含中文文字的本地 SVG，按钮只提供无障碍标签，不再叠加可见文字。目录与笔记使用 `ReadingSheet`；H5 支持焦点约束、Esc 关闭，未保存的笔记修改由业务页提醒。

后端知识点接口返回 `bodySource`、`bodyCourseIds` 和 `supportingCourses`。同考试、已发布且未删除的图文配套课按创建顺序作为正文；原知识点正文不被改写，全部图文配套课下架后自动恢复。此接口不返回受保护的课程正文，课程仍从受权限保护的接口读取。后台保存预览可包含草稿课程，并标记未发布。

`KnowledgeCourse` 直接展示视频、音频或图文，不再先点击卡片展开。视频不自动播放；`ReadingAudio` 在 H5 使用原生音频并处理播放启动时离开造成的取消，在小程序使用 uni 音频实例，均提供播放、暂停和进度拖动，离开或销毁时停止。音视频和讲义继续通过原资源票据、验证码及权限流程读取，不复制资源、不新增公开媒体地址。

## 验证范围

章节练习以章为题目队列，首页提供“开始本章练习”，节列表仅展示本章结构；旧 `sectionId` 链接自动定位所属章，并保留已存的节练习作答与草稿。章内按节排列、多知识点关联题去重，最后一题显示“本章结束”。未提交完不能继续下一章；完成后主按钮进入同科目下一个有题的章，跳过空章，不跨科目。到最后一个有题的章时，若前面仍有未完成章，提供“继续未完成章节”；全部有题章节完成后才显示“完成本科目”。章间使用替换路由避免堆积练习页，返回仍退出到来源页；重新选科目统一回刷题首页。知识点、错题、收藏与智能计划仍保留各自的题目范围。

`tests/practice-chapters.browser.mjs` 覆盖跨节组章、旧作答迁移、漏题阻断、跳空章、刷新恢复、最后一章先练、科目结束与选科目出口。

刷题页复用 `CircleAction` 和 `ReadingSheet`，题目、答题卡、笔记与关联知识点遵循品牌蓝、白色阅读区、浅灰蓝底的统一层级。`ActionButton` 提供 H5 键盘 Enter/Space、按钮语义、禁用与加载行为，具体外观由调用方定义。新旧题目共用 `ConfiguredQuestion`：单选、多选、判断均显式确认；材料、共用选项、小题组、文本答案由后台题型定义驱动；多选部分得分、自评和 AI 评分展示服务端结果，评分失败不显示为零分。

本轮进度只计已提交题目，历史作答需主动查看，不自动计入本轮。草稿、题目队列、已提交快照和笔记草稿按用户/考试/练习范围保存；切题、刷新或返回可恢复。未提交题目的版本变化会清除旧作答草稿，已提交记录按其快照复习。错题、收藏、学习计划的队列在本轮内固定，开始新一轮时重新读取；不改变后台学习计划、掌握程度或薄弱项算法。后台或隐藏页面暂停计时，结束时提示未答数，正确率仅统计已判分的客观题。笔记关闭保留本机草稿，保存失败就地提示。

`tests/practice-session.browser.mjs` 使用隔离数据库验证多题型、丢失响应后的幂等重试、草稿恢复、历史排除、自评/AI 状态同步、笔记保存失败、关联知识点返回、账户隔离和手机/横屏布局。AI 评分界面使用模拟结果，不调用收费模型；真实 AI 评分服务仍取决于后台配置。小程序构建通过不等同于真机验收。

知识点详情的图文课与无配套课顶部，按用户提供的深色文章页参考，使用深灰蓝底和倾斜叠放的 SXB 描边字母、细点纹理 SVG；字母全部为路径，不依赖字体或外部图片。标题与导航用浅色前景，白色正文以顶部圆角衔接，不使用书本插画或浅色渐变。媒体页维持遮罩导航。课程类型分别标记为图文课、视频课、音频课，重复类型合并。正文下精品课与练习使用按内容宽度排列的浅色按钮，不通栏。`ReadingSheet` 关闭图标为 19px，透明 44px 点击区域，使用 flex 居中。用户主动取消讲义验证码静默退出，下载失败仍保留错误反馈。

知识目录浏览器回归覆盖科目/章选择、点击第三章后回到第一章、横向导航、折叠、考试隔离、短标题、动画与响应式布局。小程序构建仅验证编译，真机手势仍需发布体验版验证。

## 刷题错误反馈

答对后的结果文字使用绿色 `#237355` 和 700 字重，保持原有 14px 字号。

只有服务端确认客观题错选或漏选时，答题卡片边框变红，错选项为粉底、红字、红边；页面外框保持原样，题干上方不增加额外提示条。部分得分保留其实际得分，不把主观题低分、待评或评分服务失败误标为答错。

新提交的错误结果在首个错误小题的答案解析顶部覆盖倾斜圆形双圈印章，仅显示“答错”两字，播放一次盖下动效，约 3.2 秒后消失，不占正文布局、不拦截操作。长题目在解析不可见时滚动到解析。切题、重新练习、离开页面清理动效；查看已提交或历史作答只显示静态错误配色，不重播盖章。系统减少动态效果时显示静态印章后按时移除。

## PracticeCompletion 章节完成弹窗

复用 `ReadingSheet appearance="celebration"` 的遮罩、焦点约束与关闭行为。金黄到奶油色底、浮雕金色 SVG 奖牌、缓慢旋转的放射光与轻微星光，按用户提供的参考图定制。完成页仅三个操作：主按钮“继续下一章”（末章按进度显示“继续未完成章节”或“完成本科目”），下排“作答数据 / 重练本章”。全部提交只表示完成，不意味着全部答对。

“作答数据”在同一个弹窗内切换，展示章节名称、总题数、提交数、客观题正确率、用时、主观题已评分得分和逐题状态；点击题号关闭弹窗并回到对应题目。主观题仅累计服务端已确认的自评/AI 小题得分，分母为已评分小题满分，待评或失败项单独提示、不记零分；历史作答不计入本轮。查看统计期间暂停练习计时。

尚有未提交题时展示未点亮奖牌，按实际进度鼓励，主按钮“继续完成”回到第一道未提交题，不能跳下一章。重练继续使用确认弹窗，不清除服务器历史及笔记。

SVG 均为仓库静态资源，无额外网络依赖。减少动态效果时停止动画；页面隐藏或键盘焦点进入完成区时暂停。小屏、横屏及放大文字允许弹窗内滚动，操作区包含底部安全间距。浏览器回归覆盖 320/375/390/430px、横屏、放大文字、真实动画变化与减少动态效果；小程序只完成编译验证，未替代真机验收。
