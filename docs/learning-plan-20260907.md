# 学习计划第一版（2026-09-07）

## 使用入口

- H5：`http://127.0.0.1:5174/#/pages/learning-plan/index`，首页和刷题首页均有入口。
- 后台：`http://127.0.0.1:5180/#exams`，考试分类、考试归属、考试日期、计划默认规则。
- 用户按考试保存计划；后台默认规则不替用户指定学习范围，也不覆盖用户已保存的选择。

## 已实现规则

- 分类 → 子分类 → 考试 → 科目 → 章 → 节 → 知识点 → 题。分类可新增、改名、排序及停用；考试可以改名和调整分类。
- 科目和章可多选，包含章下已发布的客观题。节与章分别处理，服务端校验内容所属考试和层级。
- 自动模式按剩余题数及剩余学习日分配整数余数，例如 480 题 / 9 天分为 54、54、54、53、53、53、53、53、53。
- 用户可修改每日题量、最多三个每周休息日，并临时跳过今天。预览显示未来七个日历日；低于覆盖所需题量时提示预计未覆盖题数。
- 同一轮内一道题重复作答只计算一次覆盖进度；自由练习中完成范围内的题也计入。完整覆盖后自动进入下一轮，历史作答保留。
- 巩固顺序优先未答和最近答错的题，再考虑 1、3、7、14、30 天复习间隔。此为可解释的规则排序，不是 AI 生成安排，也不是经验证的个体遗忘预测。
- 课程、错题、笔记是非计量提醒，仅存在真实相关内容时出现。课程提醒只对应节级精讲课。权益不足时提示对应考试会员权益。
- 初级默认备考阶段 90 天、中级 120 天，默认冲刺阶段 14 天，可在后台修改。
- 当前考试年度取该考试尚未结束的最早考试日期，所有用户共用。到期沿用已配置的下个年度；后台需维护未来考试日期。
- 前端加载失败可重试，保存不会降级为只写本地缓存；计划和实际进度来自持久化数据库。

## 本次边界

- 考前小抄保留提醒选择及 SVIP 权益入口条件。独立小抄文档、上传、阅读和下载业务属于后续功能，尚未实现；没有已发布小抄时不生成虚假提醒。
- 知识点课程仍使用已有的知识点关联内容结构，可与节级课程区分；新的图文/音视频/讲义展示暂不扩展。
- 当前计划计量为客观题，主观题 AI 判分不在本次范围。
- H5 站内展示提醒，没有新增短信、系统推送或小程序订阅消息。
- 修改范围时历史作答重新匹配新范围，保存后以服务端返回的轮次和进度为准。
